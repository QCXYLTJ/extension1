扩展名：胜负统计（可载入记录版）
作者：157
主要功能：统计各模式武将胜负场数，附带简易的胜率排行榜
当前状态：已完结，可任意分享、修改、移植
使用须知：
◆扩展设置界面第一个选项［区分当前游戏模式］开启与关闭记录的胜率除个别模式存放位置完全不一致，请根据个人喜好谨慎选择！
▲当然也可以身份、对决模式开启［区分当前游戏模式］，其余模式关闭［区分当前游戏模式］，请以大模式分配作为基本单位
▼魏体选项功能须重启游戏才能刷新
★受限于一些模式，开启［区分当前游戏模式］后开始游戏才会加载胜负场数相关显示，望悉知
■身份模式、斗地主模式、单挑模式武将胜负场数将按照身份/先后手分开记录，由于对决模式的特殊性，无法将其按照先后手/冷暖方进行记录
此外修复个人此前制作的胜率统计功能中3v3v2模式胜负判定错误
声明：
●此扩展不在维护更新范围内
●复制多个记录时如存在个别复制失败，请多尝试几次
●不记录挑战模式随从胜负场数
●由于一些情况无法检测到武将发生变更，［更换武将角色］只能记录游戏开始时和游戏结束时的场上武将，故未设〔都记录〕选项，此外部分模式游戏开始时并不存在武将，无法记录，所以用〔记录最初的〕可能会缺少记录
●［尝试记录全场武将］是基于模式的基本游戏机制计算的，故OL董昭局可能会错误记录，如遇到请关闭［尝试记录全场武将］或开启［其他阵营视为同一阵营］，这些都是即时生效的
特殊：
此版本［复制当前模式武将胜负记录］和［载入当前模式武将胜负记录］功能相辅相成，前者可用以导出记录，后者可用以导入记录，但须注意格式必须与［复制当前模式武将胜负记录］到剪贴板内容的写法一致！
此外［载入当前模式武将胜负记录］是用你写入的当前游戏模式对应武将的记录直接替换原有记录，而非在原来的基础上增加！
